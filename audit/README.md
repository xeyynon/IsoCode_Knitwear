# audit/

The design-audit trail for the UI work: audit reports (`AUDIT-01` to `AUDIT-03`), the plan and progress notes (`POA-UIUX.md`, `PROGRESS.md`), the Tamil review list (`TAMIL-REVIEW.md`), and the screenshots they cite.

Some of these notes mention files under `md/` (decisions, API notes, the run-rate write-up). The `md/` folder is working notes and is kept out of this repository, so those references do not resolve in a clone. What is in the repository instead: `docs/builds/` and `CHANGELOG.md` (what each build changed and how it was checked), `docs/status.md`, `deployment.md`, and these audit files.
